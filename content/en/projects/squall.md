## About the Project

Squall is an anycast routing platform that carries traffic from global ingress servers over an internal fabric to the exit node closest to the origin.  
It incorporates the learnings from the routing project with enhancements to make it more scalable and automated.  
Currently still running in a closed beta for the PenguinNetwork as a way of Dogfooding.  
It is built using a combination of Go, Ansible, and Agentic Coding.
